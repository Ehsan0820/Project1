A little bit about this project.

This site started as a simple "Hello, World!" page and grew into a small three-page project: a home page, this about page, and a way to get in touch. It's built with nothing but plain HTML, CSS, and a touch of JavaScript — no frameworks, no build step.

The goal was to keep things lightweight while still feeling polished: a soft animated gradient backdrop, drifting light particles, and a consistent glass-card look carried across every page.
